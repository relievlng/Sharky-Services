A few things to know

Questions, answered.

Which server does it support?

Sharky Macro is built for the Logic FiveM server. Fishing and metal detecting are tuned specifically for it.

What do I need to run it?

A Windows PC. The app is a small desktop tool with a draggable, always-on-top window and F6 / F7 hotkeys.

How is my key delivered?

Straight to your Discord DMs. After you sign in and get a pass, the bot sends your license key, invoice ID, and the download instantly.

Can I move it to a new PC?

Each license locks to one machine. If you change computers, open a ticket in Discord and staff can reset the machine lock on your key.

Is this affiliated with the game or server?

No. Sharky Macro is an independent tool and isn't endorsed by or affiliated with FiveM or any server. Use it at your own discretion.
